# Implement the assigned task

Read the handoff and applicable project instructions. Work in the assigned checkout, preserve unrelated changes, and run checks appropriate to the task. The project and the assignment determine what to implement and whether publication is requested.

If the handoff includes a GitHub context file, read it for the saved issue or PR details. If key information is missing, report that input is needed instead of guessing.

Follow the result instructions in the assignment. Generic handoffs use the supplied `astack run finish` command to report completion, failure or a need for input. Summarize changes and checks accurately. Attach detailed result files with `--artifact <relative-path>` if useful. A successful report records the result; it does not itself push, publish or clean up work.
